# Phosphor 0.2.0

Phosphor supports checking for updates and installing new versions through Sparkle.
Update preferences are available in Settings, and Check for Updates is available in the application menu.

Install this version manually to enable future updates.
Phosphor uses a fresh application identity and leaves ADSB Radar's existing settings and caches untouched.
Local reception still uses a separately installed `readsb` decoder.
