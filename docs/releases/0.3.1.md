# Phosphor 0.3.1

The selected aircraft sidebar now groups identifiers, aircraft details, and telemetry in a clearer layout.
Long identifiers and owner/operator names wrap, and the map-pin action brings the selected aircraft into view.

Likely routes can be expanded or collapsed.
Known routes start expanded, while unknown and loading routes start collapsed.
Your choice stays in place as the selected aircraft updates.

Fixed the View menu losing its hover highlight during radar redraws, making the Labels and Trails submenus reliable to open.

Install this update through Check for Updates in the Phosphor menu, or download the app archive.
Existing Phosphor settings and cached aircraft details are preserved.
