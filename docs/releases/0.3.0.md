# Phosphor 0.3.0

Aircraft details now show readable model names and available owner/operator information.
Search Contacts by model name, type code, or owner/operator, with known details retained between launches.

The selected aircraft's inspector can show a likely departure and destination, including intermediate airports when available.
These are callsign database matches and may describe multiple legs rather than the current flight.

Aircraft labels now default to registration, falling back to callsign and then address.
Choose your preferred identifier in Settings.

Filter airport markers by size and scheduled-service status in the Map controls.
Use the mouse wheel to zoom around the pointer and two-finger trackpad scrolling to pan.

Install this update through Check for Updates in the Phosphor menu, or download the app archive.
Existing Phosphor settings and cached aircraft details are preserved.
